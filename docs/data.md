# Data handoff requirements

No dataset has been selected in R1. Candidate public cohorts require evidence-based review before integration.

The handoff must document source, access method, license, version, sample counts, clinical variables, survival time and event definitions, genomic modalities, gene identifiers, subtype labels, patient/sample mapping, missingness, duplicate handling, and cohort limitations.

Use de-identified public research data only unless explicitly authorized otherwise. Do not upload or log personally identifiable health information.
