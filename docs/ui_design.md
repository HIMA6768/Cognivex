# UI design

R1 retains the responsive navy/slate/blue Streamlit visual system, white content surfaces, visible keyboard focus, safe escaped empty-state copy, and mobile stacking below 768px.

The product identity is **Breast Cancer Prognosis & Subtype Classification**, with the subtitle “Clinical and genomic research analytics” and a text-labelled “Research prototype” status.

Every page uses concise pending-data or pending-model content. No charts, cohort counts, scientific metrics, subtype labels, gene rankings, or patient results are fabricated. A persistent warning states that the application is research/educational only and must not be used for patient care.
