# Model evaluation boundary

No evaluation values exist in R1.

Future survival evaluation must respect censoring and report a real concordance index using a documented strategy. The clinical-only and clinical-plus-genomic comparison must use a fair cohort and report the measured change rather than an example value.

Future subtype evaluation should include accuracy, macro precision, macro recall, macro F1, weighted F1, per-class metrics, and a confusion matrix where supported by the verified labels. No metric may be published before the corresponding experiment is run.
