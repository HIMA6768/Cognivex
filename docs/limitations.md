# Limitations

R3 is a data-ingestion, aggregate presentation, and engineering-quality-report foundation, not a biomedical analysis system. Its readiness status is not a clinical-quality judgment. It has no preprocessing, survival model, subtype classifier, feature importance, biological validation, evaluation metric, persistence, or monitoring integration.

The supplied clinical columns, genomic identifiers, survival endpoints, event definition, subtype labels, and mutation annotations are handoff metadata, not validated scientific conclusions. R3's 1,200-month duration sentinel is an engineering review prompt, not a medical threshold. Model artifacts, preprocessing parameters, model versions, predictions, and scientific values remain absent.

The application is a research and educational prototype. It is not validated for diagnosis, prognosis in patient care, treatment selection, or any clinical decision. It must not receive identifiable patient information.
