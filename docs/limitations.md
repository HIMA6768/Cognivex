# Limitations

R1 is a presentation and contract foundation, not a biomedical analysis system. It has no active dataset, schema validation, cohort matching, preprocessing, survival model, subtype classifier, feature importance, biological validation, evaluation metrics, persistence, or monitoring integration.

No clinical columns, genomic identifiers, survival endpoints, event definitions, subtype labels, model artifacts, preprocessing parameters, model versions, or scientific values have been assumed. These remain pending data/model handoff.

The application is a research and educational prototype. It is not validated for diagnosis, prognosis in patient care, treatment selection, or any clinical decision. It must not receive identifiable patient information.
