# Limitations

R2 is a data-ingestion and presentation foundation, not a biomedical analysis system. It has a validated canonical cohort package and aggregate cohort matching, but no data-quality decision policy, preprocessing, survival model, subtype classifier, feature importance, biological validation, evaluation metric, persistence, or monitoring integration.

The supplied clinical columns, genomic identifiers, survival endpoints, event definition, and subtype labels are handoff metadata, not validated scientific conclusions. Model artifacts, preprocessing parameters, model versions, predictions, and scientific values remain absent.

The application is a research and educational prototype. It is not validated for diagnosis, prognosis in patient care, treatment selection, or any clinical decision. It must not receive identifiable patient information.
