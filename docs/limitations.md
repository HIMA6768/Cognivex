# Limitations

This is a pre-model P1 foundation, not a production assessment system. It does not include Streamlit pages, image upload or validation implementation, classifier or localizer adapters, ONNX runtime integration, a decision policy, production threshold calibration, or external service access.

Image dimensions in `ThresholdSettings` are provisional development-only defaults. Model confidence is optional and has no calibrated value. Model preprocessing, model choice, model index mappings, metrics, and production thresholds are unknown. Pending AI model handoff.

No production readiness, accuracy, security, deployment, or operational claims are made. Credentials and real external-service values are intentionally absent.
