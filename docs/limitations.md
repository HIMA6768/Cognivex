# Limitations

R4 is a data-ingestion, quality, eligibility, and preprocessing foundation, not a biomedical analysis system. Its readiness status is not a clinical-quality judgment. It has no survival model, subtype classifier, feature importance, biological validation, evaluation metric, persistence, or monitoring integration.

The supplied clinical columns, genomic identifiers, survival endpoints, event definition, subtype labels, and mutation annotations are handoff metadata, not validated scientific conclusions. R3's 1,200-month duration sentinel is an engineering review prompt, not a medical threshold. R4 preprocessing policies are engineering contracts rather than evidence of model validity. No model artifact, fitted production preprocessing artifact, prediction, or scientific performance value exists.

The application is a research and educational prototype. It is not validated for diagnosis, prognosis in patient care, treatment selection, or any clinical decision. It must not receive identifiable patient information.
