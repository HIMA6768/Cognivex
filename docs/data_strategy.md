# Data Strategy & Modeling Plan

- **Dataset:** METABRIC, supplied through a Kaggle-derived merged clinical/RNA/mutation CSV. The exact Kaggle URL, dataset version/date, and license are still **PENDING CONFIRMATION** in `dataset_provenance.json`; they must not be invented.
- **Canonical prepared dataset:** `METABRIC_prepared.csv`, generated by `prepare_data.py`. It normalizes the known `Positve` typo, maps missing/stage-0 `tumor_stage` values to categorical `Unknown`, and converts the source survival coding (`0=Deceased, 1=Living`) to the application survival convention (`1=Deceased/Event, 0=Living/Censored`).
- **Evaluation protocol:** Reproducible 70/15/15 patient-level Train/Validation/Test split locked in `manifest.csv` using `random_state=42`. The fixed seed makes the split reproducible; it **does not by itself prevent leakage**. Leakage control also requires unique patient-level partitioning and strict training-only fitting of every learned preprocessing or selection step.
- **Leakage-control rule:** Imputation, scaling, categorical encoding, variance filtering, gene filtering, feature selection, and hyperparameter tuning must be fitted using the **training split only**. Validation/test data may only be transformed with parameters learned from training data.
- **Clinical baseline (Track A):** Cox Proportional Hazards predicting overall survival months using the seven clinical baseline features in `feature_groups.json`.
- **Clinical + Genomic (Track B):** Penalized survival model (e.g. Coxnet or another justified survival-compatible model) using mRNA Z-score features and selected clinical variables, evaluated on C-index delta versus Track A. Mutation features are available as a separate group and should only be added if the modeling experiment explicitly justifies their encoding and use.
- **Subtype (Track C):** Multi-class subtype classification using the taxonomy/mapping in `subtype_labels.json`. `NC` rows are excluded only from Track C, not from valid survival modeling records.
- **Gene importance:** Rankings are model-associated/correlational and must not be presented as evidence of biological causality.
- **Provenance blocker:** Exact Kaggle URL, version/date, and license must be confirmed before the dataset handoff is treated as final provenance documentation.
